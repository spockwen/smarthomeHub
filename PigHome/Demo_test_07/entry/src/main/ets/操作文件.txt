

----------------------------------------------
DevEco Studio 6.1.1.280 对应的是 API 14（HarmonyOS NEXT 最新稳定版）
用 Preferences——轻量级本地存储（数据存在手机本地，卸载 App 才丢失，重启手机不会丢失。）


第1层（静态布局）：只有外形，能看不能点
    → 此时家具就是一个圆角矩形，上面有图标和文字
    → 你能看到"客厅主灯💡"的卡片放在正确的位置

第2层（筛选功能）：点击"客厅"只显示客厅设备
    → 家具仍然是静态卡片，但能根据房间过滤显示/隐藏

第3层（交互功能）：点击卡片能开关
    → 家具变成"有开关逻辑的按键"（你的叫法完全正确，不会混淆）
    → 点一下→变蓝→显示"运行中"
    → 再点一下→变白→显示"已关闭"
    → 这时候每个家具就是一个功能完整的"控件"

第4层（高级交互）：拖动条、编辑模式
    → 空调卡片：加温度拖动条
    → 窗帘卡片：加开合度拖动条
    → 编辑模式：改变卡片大小
