===========================================================
  一、项目概述
===========================================================

PigHome 是一个基于 HarmonyOS NEXT 开发的智能家居控制 App，使用
ArkTS 语言 + ArkUI 框架开发。支持通过 MQTT 协议与智能家居网关通信，
实现对灯光、空调、窗帘、投影仪等设备的远程控制。

■ 目标平台：HarmonyOS API 14（SDK 6.1.1）
■ 应用类型：Entry 模块（独立安装）
■ 总源文件数：16 个 ArkTS 文件
■ 总代码行数：约 2,800 行
■ 支持的页面数：5 个 Tab 页面
■ 设备数量：17 个设备元数据 / 8 个 MQTT 可控设备

===========================================================
  七、MQTT 通信协议（EMQX 网关）
===========================================================

■ 连接地址
  URL: ws://10.0.2.2:8083/mqtt
  Client ID: pig_home_app_xxx（随机生成）

■ 主题约定
  home/device/{deviceId}/state    → 设备上报状态（APP 订阅）
  home/device/{deviceId}/command  → APP 下发指令（设备订阅）

■ 指令格式
  开关：     {"action": "toggle", "on": true/false}
  调节：     {"action": "adjust", "value": 26}
  场景：     {"action": "scene", "scene": "回家模式"}

■ 状态推送
  设备状态按 topic 推送：
  home/device/{deviceId}/state/app → APP 接收端
  格式：{"on": true, "brightness": 80, "timestamp": 1234567890}

===========================================================
  十、开发注意事项
===========================================================

1. 新增设备时：
   - 在 DeviceStateService.ets 的 ALL_DEVICES 数组添加元数据
   - 在 KEYS 对象添加对应的 AppStorage 键名
   - 在 MqttService.ets 的 DEVICE_NAME_TO_ID 添加映射
   - 在 HomePage.ets 的 getDeviceCard() 添加对应卡片渲染分支

2. 新增场景时：
   - 在 DeviceStateService.ets 的 executeScene() 添加分支
   - 在 SmartPage.ets 添加新的 SceneModeCard 实例

3. 新增页面时：
   - 在 main_pages.json 注册路由
   - 在 Index.ets 的 Tabs 中添加 TabContent

4. MQTT 连接：
   - 地址 10.0.2.2 是 Android 模拟器 loopback，真实设备需改为
     实际网关 IP
   - 断线自动重连间隔 5 秒
   - 心跳保活间隔 30 秒

5. ArkTS 严格模式限制：
   - 禁止索引签名 [key: string]: type
   - 禁止索引访问 obj[key]
   - 对象字面量必须匹配显式声明的接口/类
   - JSON 操作需手动拼串，不可用 JSON.stringify/parse
