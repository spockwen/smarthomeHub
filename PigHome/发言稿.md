**发言内容：**

接下来，我为大家展示第一个亮点——**界面与响应效率**。

- **跨列卡片**（2×2）：空调，包含温度调节和模式显示
- **横放卡片**（2×1）：电动窗帘，包含开合度调节

**【展示操作】**：
- 📱 在鸿蒙APP中滑动查看不同设备卡片

### 3.1 设备注册接口设计（4:00 - 4:45）

**发言内容：**

请看我们的设备注册接口设计：

```typescript
interface DeviceRegistration {
  deviceId: string           // 设备唯一标识
  deviceName: string         // 设备显示名称
  deviceType: string         // 设备类型
  manufacturer: string       // 制造商
  protocol: string           // 通信协议
  topicConfig: TopicConfig   // MQTT主题配置
  capabilities: Capability[] // 设备能力列表
}
```

## 【第四部分：亮点三 — 协议安全】（5:30 - 7:00）

**发言内容：**

接下来展示第三个亮点——**协议安全**。

这是最容易实现但非常重要的加分项。我们实现了**全链路安全架构**，覆盖传输层、数据层、密钥层三个维度。

### 4.1 传输层安全 — TLS 1.3（5:30 - 6:00）

**发言内容：**

首先展示**传输层安全**。我们的MQTT通信固定使用8883加密端口，全链路采用TLS 1.3最新加密算法，支持双向证书认证。

**【展示操作】**：
- 🖥️ 展示EMQX Dashboard（http://localhost:18083）
- 🖥️ 展示TLS配置页面
- 🖥️ 展示连接状态（已加密）

### 4.2 数据层安全 — AES-256（6:00 - 6:30）

**发言内容：**

接下来展示**数据层安全**。APP下发控制指令前进行AES-256对称加密，报文到达设备端自动解密执行。

**【展示操作】**：
- 🖥️ 展示加密后的MQTT消息（十六进制）
- 🖥️ 展示解密后的原始指令
- 🖥️ 说明即使泄露也无法破译

### 4.3 密钥层安全（6:30 - 7:00）

**发言内容：**

最后展示**密钥层安全**。我们的AES密钥安全存储于系统密钥库中，不在代码中硬编码，支持密钥定期轮换。

**【展示操作】**：
- 🖥️ 展示配置文件中的密钥管理方式
- 🖥️ 说明环境变量保护机制
