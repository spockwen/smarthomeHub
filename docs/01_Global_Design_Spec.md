## 1. 设计语言与核心原则

### 1.1 HarmonyOS Design 三大核心原则

HarmonyOS Design 官方设计语言围绕三大核心原则展开，智能家居 APP 作为高频交互场景，应深度贯彻：

| 原则 | 内涵 | 智能家居场景落地 |
|------|------|------------------|
| **简约 Simple** | 去除一切非必要元素，内容即界面 | 首页以设备状态为核心，无多余信息层级；控制面板一步直达 |
| **自然 Natural** | 符合人类直觉，操作可预期 | 开关即按即开，滑动即调即变；设备状态实时反馈，所见即所得 |
| **通透 Alive** | 界面如同活的生命体，有呼吸有反馈 | 每一个触控都有光感响应；设备状态变化时产生渐变光晕扩散 |

### 1.2 视觉风格定位

```
┌─────────────────────────────────────────────────────┐
│                  视觉风格定位                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│   关键词：清透 / 光感 / 轻盈 / 沉浸                   │
│                                                     │
│   背景层 ─────── 轻量化微模糊，传递空间层次           │
│   卡片层 ─────── 高光边框 + 柔和阴影，悬浮感           │
│   控件层 ─────── 动态光晕，呼吸感动画                 │
│   内容层 ─────── 纯内容呈现，无装饰干扰              │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 1.3 无障碍设计要求

| 要求 | 规格 |
|------|------|
| 对比度 | 主文字与背景对比度 ≥ 4.5:1（WCAG AA） |
| 触控热区 | 最小 44vp × 44vp（对应屏幕密度 ≥ 160ppi） |
| 焦点可见性 | 智慧屏场景最小 64vp × 64vp，支持焦点边框 |
| 字体缩放 | 支持系统字体放大（最大 200%） |
| 色彩无障碍 | 状态信息不以颜色为唯一传达手段，需配合图标或文字 |

## 2. 色彩系统

### 2.1 色彩语义定义

依据 HarmonyOS Design 官方规范，智能家居 APP 建立以下语义化色彩体系：

| 语义色名称 | Hex 值 | RGB | 用途场景 |
|-----------|--------|-----|---------|
| **品牌主色 / Brand Primary** | `#007DFF` | (0, 125, 255) | 主按钮激活态、开关 ON 状态、选中态、链接 |
| **品牌辅色 / Brand Secondary** | `#00A5FF` | (0, 165, 255) | 渐变、hover、光感叠加层、辅助高亮 |
| **成功色 / Success** | `#00C854` | (0, 200, 84) | 设备在线、正向操作反馈、执行成功 |
| **警告色 / Warning** | `#FFB800` | (255, 184, 0) | 离线设备提示、电量不足、即将过期 |
| **错误色 / Error** | `#FF3B30` | (255, 59, 48) | 设备异常、控制失败、危险操作 |
| **中性灰 / Neutral** | `#785E5E` | (120, 94, 94) | 次要文字、辅助说明（深色模式） |
| **中性灰 / Neutral** | `#99A0A8` | (153, 160, 168) | 次要文字、辅助说明（浅色模式） |

### 2.2 背景与表面色（Light Mode）

| 层级名称 | Hex 值 | 用途 |
|---------|--------|------|
| **背景色 / Background** | `#F2F5F7` | 页面根背景，营造深度空间感 |
| **表面色 / Surface** | `#FFFFFF` | 卡片、控件底板、模态弹窗背景 |
| **抬高色 / Elevated** | `#FFFFFF` | 悬浮按钮、深层弹窗（通过阴影区分） |
| **分割线 / Divider** | `#0F000000` | 列表分割线（1vp，8% 黑色） |

| 层级名称 | Hex 值 | 用途 |

```typescript
@Extend(Column) function cardSurface() {

  .borderRadius(16)

    radius: 8,
    color: '#0F000000',
    offsetX: 0,
    offsetY: 4
  })
}

// 深色模式适配（通过资源限定符或媒体查询）
```

## 4. 间距系统

### 4.1 基准网格

鸿蒙设计采用 **4pt 基准网格**（4-point Grid System），所有间距均为 4vp 的整数倍：

```
┌───┐ ← 4vp（xs）
│ xs│
└───┘
┌─────┐ ← 8vp（sm）
│  sm │
└─────┘
┌───────┐ ← 12vp（md）
│   md  │
└───────┘
┌─────────┐ ← 16vp（lg）
│    lg   │
└─────────┘
┌─────────────┐ ← 24vp（xl）
│     xl      │
└─────────────┘
┌───────────────┐ ← 32vp（xxl）
│     xxl       │
└───────────────┘
```

### 4.2 间距等级速查

| 间距等级 | 尺寸 | 适用场景 |
|----------|------|----------|
| **xs** | 4vp | 组件内部最小间距、图标与文字间距 |
| **sm** | 8vp | 列表项内部元素间距、紧凑布局 |
| **md** | 12vp | 区块内多元素间距 |
| **lg** | 16vp | 区块间标准间距、页面左右安全边距（手机） |
| **xl** | 24vp | 大区块分隔、卡片组间距 |
| **xxl** | 32vp | 页面顶部/底部与内容的全局间距 |

### 4.3 安全区域

| 设备形态 | 页面左右安全边距 | 页面上下安全边距 |
|----------|-----------------|-----------------|
| 手机 | 16vp | 顶部系统栏自动规避，底部 24vp |
| 平板 | 24vp | 顶部系统栏，底部 24vp |
| 智慧屏 | 48vp | 顶部 32vp，底部 64vp（遥控器误触区） |
| 智能手表 | 8vp | 顶部 4vp，底部 8vp |

### 4.4 组件间距配置示例

```typescript
// ArkUI 间距配置示例
Column() {
  // 设备卡片组
  Column() {
    // 设备图标与名称间距 8vp（sm）
    Row() {
      Image($r('app.media.icon_device')).width(48).height(48)
      Column() {
        Text('客厅灯').fontSize(22).fontWeight(FontWeight.Medium)
        Text('已开启').fontSize(12).fontColor('#99000000')
      }
      .margin({ left: 8 }) // sm 间距
    }
    .padding({ left: 16, right: 16, top: 12, bottom: 12 }) // md 间距
  }
  .margin({ bottom: 12 }) // md 间距

  Column() {
    // ...
  }
  .margin({ bottom: 24 }) // xl 间距
}
.padding({ left: 16, right: 16, top: 24, bottom: 24 }) // lg 间距
```

## 5. 圆角规范

### 5.1 圆角层级

| 组件类型 | 圆角半径 | 说明 |
|---------|---------|------|
| **小控件** | 8vp | 图标按钮、小尺寸触发区 |
| **表单控件** | 12vp | 输入框、选择器 |
| **卡片/容器** | 16vp | 设备卡片、信息卡片、快捷入口 |
| **大模态弹窗** | 24vp | 确认弹窗、底部抽屉 |
| **全屏页面** | 0 | 无圆角，沉浸式体验 |
| **底部导航栏** | 24vp（顶部） | TabBar 顶部圆角 |

### 5.2 圆角与光感关系

```
┌──────────────────────────────────────────────────────┐
│              圆角与光感层级关系                       │
├──────────────────────────────────────────────────────┤
│                                                      │
│   border-radius: 8vp（圆角较小）                     │
│   → 适合小控件，光感集中在四角内侧                     │
│   → 外发光模糊半径上限 10vp                           │
│                                                      │
│   border-radius: 16vp（中圆角）                      │
│   → 适合卡片，光感均匀分布在整个边框                    │
│   → 外发光模糊半径 15-20vp 效果最佳                   │
│                                                      │
│   border-radius: 24vp（大圆角）                      │
│   → 适合弹窗，光感柔和过渡到背景                       │
│   → 外发光模糊半径可达 30vp                          │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 5.3 圆角配置代码示例

```typescript

  // ...
}
.width('100%')

// 底部弹窗
PromptAction.showDialog({

// 底部弹窗圆角由系统 PromptAction 统一处理，无需自定义
```

## 6. 沉浸光感视觉模型

### 6.1 光感设计理念

沉浸光感（Halo / Immersive Light Interaction）是 HarmonyOS Design 的标志性交互范式。其核心思想：

> **每一个可触控的控件，都如同真实物理世界中的发光体，通过光晕、透明度变化、光影层级来传递状态与反馈。用户触碰的不只是一个静态色块，而是与一个有温度、会呼吸的界面在交互。**

### 6.2 光感视觉层级模型

```
╔═══════════════════════════════════════════════════════╗
║               沉浸光感视觉层级模型                    ║
╠═══════════════════════════════════════════════════════╣
║                                                       ║
║   ┌─────────────────────────────────────────────┐    ║
║   │                                             │    ║
║   │         ● ● ● ● 外发光层 ● ● ● ●           │    ║
║   │        (Ambient Glow / Outer Halo)          │    ║
║   │                                             │    ║
║   │   blur: 15-40vp   opacity: 15-40%           │    ║
║   │   颜色随状态语义动态变化                     │    ║
║   │                                             │    ║
║   │   ┌────────────────────────────────────┐   │    ║
║   │   │                                      │   │    ║
║   │   │         ■ ■ ■ 控件主体 ■ ■ ■         │   │    ║
║   │   │        (Surface Layer)               │   │    ║
║   │   │                                      │   │    ║
║   │   │   背景色 + 圆角 + 阴影基础层          │   │    ║
║   │   │                                      │   │    ║
║   │   │   ┌──────────────────────────────┐   │   │    ║
║   │   │   │   ══════════════════════     │   │   │    ║
║   │   │   │   内阴影层（Inner Shadow）   │   │   │    ║
║   │   │   │   top-light 底部-dark        │   │   │    ║
║   │   │   │   模拟真实物理厚度感          │   │   │    ║
║   │   │   │   ══════════════════════     │   │   │    ║
║   │   │   └──────────────────────────────┘   │   │    ║
║   │   │                                      │   │    ║
║   │   │          ← 内容区（Content）→        │   │    ║
║   │   │                                      │   │    ║
║   │   └────────────────────────────────────┘   │    ║
║   │                                             │    ║
║   └─────────────────────────────────────────────┘    ║
║                                                       ║
╚═══════════════════════════════════════════════════════╝
```

### 6.3 各层参数定义

#### 外发光层（Outer Glow / Ambient Halo）

| 参数 | 取值范围 | 说明 |
|------|---------|------|
| blurRadius | 0-40vp | 模糊半径，越大越柔和 |
| opacity | 0-50% | 透明度，叠加在控件之上 |
| color | 语义色 | 激活态蓝色（#007DFF）、成功态绿色（#00C854）等 |

#### 控件主体层（Surface）

| 参数 | 取值范围 | 说明 |
|------|---------|------|
| backgroundColor | #FFFFFF / #F2F5F7 | 背景色 |
| borderRadius | 8-24vp | 圆角 |
| border | 1vp / 0 | 边框线宽 |
| shadow | radius 4-12vp | 基础阴影 |

#### 内阴影层（Inner Shadow）— 可选

| 参数 | 说明 |
|------|------|
| top-light | 从顶部边缘向内 1-2vp，透明度 5-10% 白色 |
| bottom-dark | 从底部边缘向内 1-2vp，透明度 5-10% 黑色 |

## 7. 组件通用光感参数配置

### 7.1 沉浸光感按钮（Immersive Halo Button）

**场景：** 首页快捷场景入口、设备控制主按钮

**光感状态参数：**

| 状态 | glow blur | glow opacity | glow color | inner shadow | scale |
|------|-----------|--------------|------------|--------------|-------|
| Default | 0 | 0 | transparent | — | 1.0 |
| Hover | 10vp | 20% | #007DFF | — | 1.02 |
| Pressed | 6vp | 30% | #007DFF | 底部 5% | 0.97 |
| Active | 20vp | 40% | #007DFF | — | 1.0 |
| Disabled | 0 | 0 | transparent | — | 1.0 |

**动画规格：**

| 动画阶段 | 时长 | 曲线 |
|----------|------|------|
| Default → Hover | 200ms | Curve.EaseOut |
| Hover → Default | 150ms | Curve.EaseIn |
| → Pressed | 100ms | Curve.FastOutSlowIn |
| Pressed → Release | 150ms | Curve.EaseOut |
| → Active | 200ms | Curve.EaseOut |

### 7.2 设备开关（Device Toggle）

**场景：** 首页设备列表开关、详情页电源开关

**光感状态参数：**

| 状态 | Track 背景色 | Thumb 位置 | Thumb 光晕 | 扫动光效 |
|------|------------|-----------|-----------|---------|
| OFF | #E6E6E6 | 左侧（x=2） | 无 | 关闭时无扫动 |
| ON | #007DFF | 右侧（x=26） | blur 8, #33007DFF | 从左向右光感扫动 300ms |
| Transition | 过渡色 | 滑动动画 250ms | 切换瞬间产生光爆 | 光晕在 100ms 内从 0→1→0 |

### 7.3 设备卡片（Device Card）

**场景：** 首页设备列表项

**光感状态参数：**

| 状态 | 背景色 | 边框 | 阴影 | 缩放 |
|------|--------|------|------|------|
| Default | #FFFFFF | 1vp #0F000000 | radius 8 | 1.0 |
| Hover | #FFFFFF | 1vp #33007DFF | radius 10 | 1.01 |
| Pressed | #FFFFFF | 1vp #33007DFF | radius 4 | 0.99 |
| Online 指示 | — | 左侧 3vp #007DFF | — | — |
| Offline | #F5F5F5 | 1vp #0F000000 | radius 8 | 1.0 |

### 7.4 光感滑动条（Light Slider）

**场景：** 亮度调节、色温调节、音量控制

**光感参数：**

| 元素 | 参数 |
|------|------|
| Track 已填充 | LinearGradient（#007DFF → #00A5FF），从左向右渐变 |
| Track 未填充 | #E6E6E6 |
| Thumb 常态 | 24×24 圆形，fill #007DFF，shadow blur 10 |
| Thumb 拖动态 | 28×28 圆形，shadow blur 20，颜色 #33007DFF |
| 拖动动画 | duration 150ms，Curve.EaseOut |

```
     │ ◄─────────────────┘
     │
     │ (松手后恢复到 Default)
     │
     ▼ (on:true)
┌─────────┐
│  Active │
└────┬────┘
     │
     ▼ (on:false)
  ┌─────────┐
  │ Default │
  └─────────┘
```

### 8.2 状态详细说明

| 状态 | 触发条件 | 用户期望 | 视觉表现 |
|------|---------|---------|---------|
| **Default** | 初始态 | 看清楚这是什么控件 | 无光感，静态 |
| **Hover** | 手指悬停在控件上（PC 端）/ 开始触摸（mobile 端） | 告诉我"我在这里，你可以点我" | 边框光晕轻微亮起 |
| **Pressed** | 手指按下（100ms 内不抬起） | 告诉我"我正在触发你" | 控件轻微收缩，光晕向内聚集 |
| **Active** | 开关 toggled on / 场景激活 | 告诉我"这个功能已经开启" | 持续外发光，边框光晕 |
| **Disabled** | 控件不可交互 | 不给我任何操作暗示 | 整体压暗，无光感，无缩放 |

### 8.3 触控反馈时序

| 时刻 | 阶段 | 时长 | 状态 |
|------|------|------|------|
| t=0 | 触摸瞬间 | — | Default → Hover |
| t=0~100ms | 按下态 | 100ms | Hover → Pressed |
| t=100ms~ | 保持按压 | 持续 | Pressed（如果 300ms 内未抬起则触发） |
| t=触发点 | 触发执行 | — | Pressed → Active（如果是开关/切换）或 Default（如果是按钮） |
| t=触发后+150ms | 反馈消退 | 150ms | Active → Default（按钮），Active 保持（开关 ON 态） |

### A. 光感色彩语义映射

| 语义 | 颜色 | 用途 |
|------|------|------|
| 通用激活 | `#007DFF` | 默认激活态、开关 ON |
| 成功完成 | `#00C854` | 操作成功、设备在线 |
| 警告提示 | `#FFB800` | 低电量、离线 |
| 危险/错误 | `#FF3B30` | 操作失败、设备异常 |
| 柔光叠加 | `#00A5FF` | 渐变辅色、光感叠加层 |
| 中性光感 | `#000000` @ 10% | 深色模式通用光晕 |

### B. 推荐动画曲线

| 曲线名称 | 适用场景 | 特点 |
|---------|---------|------|
| `Curve.EaseOut` | 进入动画、光感亮起 | 快入慢出，自然 |
| `Curve.EaseIn` | 退出动画、光感消退 | 慢入快出，干脆 |
| `Curve.FastOutSlowIn` | 页面转场、弹性反馈 | 快慢交替，流畅 |
| `Curve.Ease` | 通用平滑动画 | 均匀加减速度 |
| `Curve.Linear` | 数值直推（如进度条） | 无缓动，线性 |
